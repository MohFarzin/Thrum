# THRUM Pulse UI — face & decisions

**Style:** achromatic-ledger (kept brand palette/type)
**Face:** Absolute black ground; green (`--accent`) only on data (uptime ring, bar segments, up KPI); chrome is ink/neutral. Primary button is near-white on dark (not green).
**Shell:** 56px icon rail + 48px top bar; phone → bottom icon bar.
**Signature element:** Fleet pulse ring + 1h heartbeat strips (THRUM’s “pulse” as the main data hue).
**Redraws:** none (palette/type kept from brand; chart hue mapped from brand green instead of #1d5fbf).
